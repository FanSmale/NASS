# NASS
Official Implementation of Neighborhood Active Stratified Sampling

We provided the official implementations of the neighborhood active stratified sampling (NASS) approach family.
The stuck pipe dataset is private and please contact us for requiring if needed. 
Users can adopt any other classification datasets to test our approach.

More details of NASS and its several variants will be supplied soon.
